# 来首东方

想听东方曲子的时候，在群里发一句 `/来首东方`。机器人会挑一首歌，告诉你曲名、作者和去哪里听。遇到同人编曲，还会列出它用到的原曲。

| 发送 | 会收到什么 |
| --- | --- |
| `/来首东方` | 一首东方原曲或同人曲 |
| `/来首原曲 红魔乡` | 一首《东方红魔乡》的游戏原曲 |
| `/来首电音` | 一首电子编曲 |
| `/来首幽闭星光` | 一首幽闭星光的歌，链接指向网易云同版本或官方 MV |
| `/来首东方 华鸟风月` | 用简体曲名找到《華鳥風月》 |
| `/来首网易云` | 从有网易云版本的曲目里随机选一首，也可加“原曲”“电音”或社团名 |
| `/东方播放 坏苹果` | 点播曲库里的《Bad Apple!! feat.nomico》 |
| `/东方播放 https://music.163.com/song?id=749768` | 点播链接指定的版本。手机分享短链、整段分享文案和单曲 ID 也可以 |
| `/东方试听 749768` | 在 QQ 群、QQ 私聊或 Telegram 听一段约 20 秒的试听 |
| `/来首东方 曲库` | 当前收录数量和社团名单 |

群友共用本群的推荐记录，私聊各自独立。符合条件的曲子优先推荐还没点到的。都听过以后，会避开最近的五首；候选少时，尽量拉开两次推荐同一首的间隔。重启后记录仍然保留。

## 安装

适用于 AstrBot 4.26.0 及以上的 4.x 版本。在管理面板打开「插件 → 安装插件 → 从链接安装」，粘贴 [GitHub 仓库地址](https://github.com/pacholigoooo/astrbot_plugin_touhou_jukebox)。本地 ZIP 可通过「从文件安装」导入。加载后即可点歌。曲库随包提供，选歌使用本地 SQLite，无需 API Key、音乐账号或模型。

曲库收录 40 首，含 12 首游戏原曲和 28 首同人曲。33 首已核对网易云上的曲目和版本，其余使用社团或发行方原播放页。网易云链接还可点播曲库以外的歌。在群里用指令带上分享链接即可，普通聊天中的链接不会触发点歌。

### 网易云播放与试听

接入 OneBot v11 的 QQ 默认发送网易云音乐卡片，可点卡片播放。协议端拒收卡片时会改发同一首歌的链接，也可在插件设置里关闭卡片。其他适配器使用单曲页。整首歌的收听范围由网易云按曲目和听众账号提供。[OneBot 音乐分享格式](https://github.com/botuniverse/onebot-11/blob/master/message/segment.md#音乐分享-)

要在对话里直接听一段，发 `/东方试听` 加曲名、网易云链接或单曲 ID。机器人从网易云公开外链截取开头最多 20 秒，发完清理本地片段。歌曲未开放外链试听时，会回复歌曲信息。试听优先使用系统 FFmpeg，插件依赖中的 `imageio-ffmpeg` 也可提供可执行文件。QQ 官方语音使用 AstrBot 的 `silk-python`，可在 AstrBot 的适配器依赖页面安装。

### QQ 官方机器人

QQ 群和私聊可用 `/东方试听` 收语音。要发送网易云单曲直链，把已通过 QQ 开放平台「消息 URL 配置」的 `music.163.com` 填进插件的「QQ 官方机器人已报备的播放域名」。没有匹配域名时会给搜索词或哔哩哔哩 BV 号。QQ 文字子频道使用文字回复。[QQ 官方消息文档](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/send-receive/send.md)

## 曲库

`data/` 下的 JSON 文件保存曲名、作者、原曲、搜索别名、播放链接和资料出处。补充曲目时可保留原播放地址，在 `netease_id` 填入同一录音版本的网易云数字 ID（字符串）。重新加载插件后生效。推荐记录位于 AstrBot 的 `data/plugin_data/astrbot_plugin_touhou_jukebox/plays.sqlite3`，从 1.0 升级后继续沿用。
